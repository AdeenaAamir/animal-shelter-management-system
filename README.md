# Animal Shelter Management System

Animal Shelter Management System is a relational database project developed to manage records of animals, shelter operations, and related data. The project uses MySQL to organize data efficiently and support CRUD functionality.

## Technologies
- MySQL
- SQL

## Features
- Relational database design
- Normalized database schema
- Full CRUD operations
- Data storage and retrieval
- Record management for shelter operations

## Project Structure
- SQL schema files
- SQL query files
- Documentation
